# Le Miroir d'Iris - Numérologie

Petite application web de numérologie pythagoricienne (chemin de vie, expression, élan spirituel, réalisation, jour de naissance, année personnelle).

**Vie privée** : tout se calcule dans le navigateur. Aucune donnée n'est envoyée à un serveur. Rien n'est conservé, sauf si la personne coche elle-même « Conserver mon profil sur cet appareil » (stockage local, effaçable via « Tout effacer »).

## Mise en ligne sur GitHub Pages
1. Créez un dépôt et déposez `index.html`, `iris_miroir_d_iris.png` et `README.md`.
2. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
3. Le site sera disponible sur `https://VOTRE-NOM.github.io/NOM-DU-DEPOT/`.
